Level.1

打家劫舍 ：相邻房屋不可偷窃的最高金额

房屋价值列表： nums = [2,7,9,3,1]   （e.g)



解题思路：

    二维数组dp[i][0] 表示第i号房屋未被偷窃的最高金额，dp[i][1]表示第i号房屋被偷窃的最高金额。[0]表示未被偷窃， [1]表示被偷窃

     

状态转移方程：

            第i号房屋未被偷窃时的最高金额：dp[i][0] = max(dp[i-1][0], dp[i-1][1])

            第i号房屋被偷窃时的最高金额：    dp[i][1] = dp[i-1][0] + num[i]  (第i - 1号房屋未被偷窃)

边界条件：dp[0][0] = 0  dp[0][1] = nums[0]

返回   max(dp[len(nums)-1][0], dp[len(nums)-1][1]) 两者中的最大值



代码实现

class Solution(object):

    def rob(self, nums):

            dp = [[0,0] for _ in range(len(nums))]

            dp[0][0], dp[0][1]  = 0, nums[0]

            for i in range(1, len(nums)):

                   dp[i][0] = max(dp[i-1][0], dp[i-1][1])

                   dp[i][1] = dp[i-1][0] + num[i]

            return max(dp[len(nums)-1][0], dp[len(nums)-1][1])



Level.2 买卖股票的最佳时机

**某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票，求最大利润



解题思路：

                dp[i]  为第 i 天卖出所得的最大利润，minPrice为前i天的最小入手价，

                

状态转移：

                    dp[i] = price[i] - minPrice

由于dp[i]只用一次，可由变量代替

代码实现:

  class Solution:

    def maxProfit(self, nums: List[int]) -> int:

        maxP = 0

        minnum = nums[0]

        for i in range(1, len(nums)):

            if nums[i] - minnum > maxP:

                maxP = nums[i] - minnum

            if nums[i] < minnum:

                minnum = nums[i]

        return maxP

**法一：滑动窗口 + HashTable**

**哈希表dic 统计**：指针j遍历字符数组 ， 哈希表统计字符arr[j]最后一次出现的索引（即重复字符第一次出现的下标）

**更新左指针 i**：根据上轮 i 和 arr[ j ] , 确保[ i + 1, j]区间无重复字符且长度最大。  （i 左指针 初始值为-1）

**更新结果res**：取上轮res 和本轮双指针区间[i +1, j]长度的最大者（ 即max(j - i, res) ) 



**Python代码实现：**

class Solution:

    def dismantlingAction(self, arr: str) -> int:

        dic,  res,  i = {}, 0, -1

        for j in range(len(arr)):

                if arr[j] in dic :

                    i = max(dic[arr[ j ]], i)

                dic[arr[j]] = j

                res = max(res, j - i)

        return res





**法二：动态规划 + HashTable**

**状态定义：**

**dp数组**：代表以arr[j]为末尾的子数组的最大长度， arr[i]代表arr[j]左边距离最近的相同字符

**哈希表统计：** 在j遍历字符数组时，哈希表统计每个字符最后出现的下标

**状态转移方程：**

右边界 j 固定 ：

（1） 当 i < 0  时：说明从数组开始到arr[j]每个字符都不一样， 此时dp[j] =dp[j-1] + 1 



i >= 0：

（2） 当 dp[j-1] < j - i 时： arr[i] 在 dp[j - 1] 区间外, dp[j] = dp[j-1] +1

（3） 当dp[j-1] == j - i 时： arr[i] 在 dp[j - 1] 区间内,  则 左边界为i， dp[j] = j - i

（4） 当dp[j-1] > j - i 时：arr[i]在dp[j - 1] 区间内 ， 同（3）则 左边界为i， dp[j] = j - i

**结果**：返回dp数组中的最大值即可

return max(dp);

丑数：

给你一个整数 `n` ，请你找出并返回第 `n` 个 丑数 。

**说明：**  丑数是只包含质因数 2、3 和/或 5 的正整数；1 是丑数。

**输入:** n = 10
**输出:** 12
**解释:** `1, 2, 3, 4, 5, 6, 8, 9, 10, 12` 是前 10 个丑数。



解题思路：

        1为丑数，质因数为2，3，5， 只需将1依次与2，3，5相乘，所得的数组其中每个数，再次与2，3，5相乘，可保证只包含因数2，3，5。

但会有重复数字出现，

因此每次取最小的丑数和2，3，5相乘

即：用三个指针代表丑数与2，3，5相乘

伪代码如下：

a，b，c = 0，0，0

i from 0 to n   do :



x，y，z = res[a]  * 2, res[b] * 3, res[c] * 5

res[i] = min(x, y, z)

if res[i] == x : a+=1

if res[i] == y : b+=1

if res[i] == z : c+=1

return res[-1]



代码如下：

class Solution:

    def nthUglyNumber(self, n: int) -> int:

        res, a, b, c = [1] * n, 0, 0, 0

        for i in range(1, n):

            x,y,z = res[a] * 2, res[b]* 3, res[c] * 5

            res[i] = min(x, y, z)

            if res[i] == x : a+=1

            if res[i] == y : b+=1

            if res[i] == z : c+=1

        return res[-1]

统计结果概率

你选择掷出 **num** 个色子，请返回所有点数总和的概率。

你需要用一个浮点数数组返回答案，其中第 i 个元素代表这 num 个骰子所能掷出的点数集合中第 i 小的那个的概率。



f(n-1)代表投出n-1个色子的解， 则f(n,x)表示投出n个色子后点数为x的概率 = add（ i from 1 to 6 ）f ( n-1, x - i ) * 1/6

此逆向思路在计算例如f( 2, 2 )时会出现越界问题

因此，**正向来谈每个f (n, x) 只对 f ( n+1, x+1) 、 f ( n+1, x+2)、...... f ( n+1, x+6) 相关** , 从而避免越界问题



class Solution(object):

    def statisticsProbability(self, num):

        """

        :type num: int

        :rtype: List[float]

        """

        dp = [1.0 / 6.0] * 6

        for i in range(2, num +1):

            tmp = [0] * (5 * i + 1)

            for j in range(len(dp)):

                for k in range(6):

                    tmp[j+k] += dp[j] / 6.0

            dp = tmp

        return dp

Level.6

### 连续天数的最高销售额

某公司每日销售额记于整数数组 `sales`，请返回所有 **连续** 一或多天销售额总和的最大值。

要求实现时间复杂度为 `O(n)` 的算法。



动态规划解析：

状态定义： dp[i] 表示以元素sales[i] 为末尾的连续子序列的最大和

转移方程：若dp[i-1] 为0 则dp[i-1]对dp[i]  产生负贡献 ， （即dp[i-1] 不如 dp[i]大），在此时应重新以sales[i]  为首项继续向后寻找最大连续子序列。

初始状态：dp[0] = sales[0] 以sales[0]为末尾的连续子序列和最大为sales[0]

return max(dp)即可

可看出dp[i]仅被dp[i+1]使用一次，因此可以在原数组上进行修改，不会影响后续子序列和的计算

代码如下：

class Solution:
    def maxSales(self, sales: List[int]) -> int:
        for i in range(1, len(sales)):
            sales[i] += max(sales[i - 1], 0)
        return max(sales)



Level.7 最长回文子串

![c9f4420d-a9c9-4520-a433-428909acf319](file:///C:/Users/DELL/Pictures/Typedown/c9f4420d-a9c9-4520-a433-428909acf319.png)



首先：（1） 单个字母是回文序列毋庸置疑， （2） 如果是两个字母，两个字母只要相等就是回文序列

状态定义： 那么考虑回文序列长度 > 2 的情况， dp[ i ][ j ] 表示从s[ i ] 到 s[ j ] 的序列是否是回文序列， 在 [ i , j ] 区间内只有 s[ i + 1 : j − 1 ] 是回文串， 并且 s[ i ] == s [ j ] 时 dp[ i ] [ j ] == True 

状态转移方程 ： P( i, j )  = P( i + 1 , j − 1) ∧ ( Si ​== Sj​ )     P( i, j ) = 子串 Si​…Sj​ 是回文串

最终的答案即为所有 P( i, j ) = true 中 j − i + 1（即子串长度）的最大值。

注意：在状态转移方程中，我们是从长度较短的字符串向长度较长的字符串进行转移的，因此一定要注意动态规划的循环顺序。



代码实现如下：

class Solution:

    def longestPalindrome(self, s: str) -> str:

        n = len(s)

        if n < 2:

            return s

        max_len = 1

        begin = 0

        dp = [[False] * n for _ in range(n)]

        for i in range(n):

            dp[i][i] = True   // 单个字母是一个回文序列

        for L in range(2, n + 1):    // 长度从小到大开始遍历

            for i in range(n):

                j = L + i - 1                          //  j  =   子序列的长度  -  起始地址  -  1

                if j >= n:

                    break

                if s[i] != s[j]:

                    dp[i][j] = False

                else:

                    if j - i < 3:                        //   即 L <  4     aba  aa   bb    aca   均是回文序列

                        dp[i][j] = True

                    else:

                        dp[i][j] = dp[i + 1][j - 1]       //动态转移方程

                if dp[i][j] and j - i + 1 > max_len:

                    max_len = j - i + 1                    // 找出最大值

                    begin = i

        return s[begin:begin + max_len]



Level.8 正则表达式匹配

![fb552886-fb68-40b9-b264-575190a44cc5](file:///C:/Users/DELL/Pictures/Typedown/fb552886-fb68-40b9-b264-575190a44cc5.png)

解题思路：

设s的长度为n， p的长度为m， 将s的第 i 个字符设为 si， p的第 j 个字符设成 pj，将s的前 i 个字符组成的子字符串记为s[ : i ]， 将p的前 j 个字符组成的子字符串记为p[ : j ]， 问题转化为s[ : n] 与 p[ : m] 是否能匹配。

总体思路是从s[ : 1] 和 p [ : 1]开始判断是否匹配，每轮添加一个字符并判断是否匹配，直至添加完整个字符串s和p。展开来看，若s[ : i ] p[ : j ]可以匹配， 那么接下来的情况有两种，

(1)添加 S i+1 后是否可匹配

(2)添加 P j+1 后是否可匹配

因此状态共有 m X n 种 ， 应定义二维状态矩阵dp， dp[ i ][ j ]表示s[ : i ] p[ : j ] 是否可以匹配.

做好状态定义后， 接下来就是根据三种字符【普通字符】， 【*】， 【 . 】，的不同功能作动态规划的转移方程

状态定义： 设状态矩阵dp, dp[ i ][ j ] 代表字符串s 前 i 个字符和 p 的前 j 个字符是否匹配

转移方程：需要注意，由于dp[ 0 ][ 0 ]是空字符状态， 因此dp[ i ][ j ]对应的添加字符是s[ i - 1], p [ j - 1]。

    当 p [ j - 1] == " * " 时， dp[ i ][ j ]当下面任一情况为True 时 为 True

            （1） dp [ i ] [ j - 2] ：即将组合 ” p[ j - 2] * “ 出现0次时是否能够匹配       例如 ： i = 2, j = 4 时， abbc    abd*， s[ : i] = ab,  p[ j - 2] = ab, 可以匹配，（ 此时*连着前面的d省略了相当于ab）

            （2） dp [ i - 1 ][ j ] and s[ i - 1] == p[ j - 2 ] : 即将p[ j - 2 ]重复一次是否匹配。  ▲！！！ 例如 ： abb   ab* 或者 aa  a*  满足 ： dp [ i - 1 ][ j ]

               (3)   dp [ i - 1 ][ j ] and p[ j -2 ] == " . " :   即将p[ j - 2 ]重复一次是否匹配.  同（2）只不过可以匹配任意一个字符

    当 p [ j - 1]  != " * " 时， dp[ i ][ j ]当下面任一情况为True 时 为 True

               (1)   dp[i - 1] [ j - 1] 且 s [ i - 1] = p[ j - 1]： 即当 s [ i - 1] = p[ j - 1]，才能匹配。
               (2)   dp[ i - 1][ j - 1] 且 p[ j - 1] = '.'          ： 即将字符 . 看作字符 s[i - 1] 时，才能匹配。

初始化： 需要先初始化 dp 矩阵首行，以避免状态转移时索引越界。

dp[ 0 ][ 0 ] = true： 代表两个空字符串能够匹配。
dp[ 0 ][ j ] = dp[ 0 ] [ j - 2] 且 p[ j - 1] = ' * '： 首行 s 为空字符串，因此当 p 的偶数位为 * 时才能够匹配（即让 p 的奇数位出现 0 次，保持 p 是空字符串）。因此，循环遍历字符串 p ，步长为 2（即只看偶数位）。
返回值： dp 矩阵右下角字符，代表字符串 s 和 p 能否匹配。

代码实现如下：

class Solution:

    def isMatch(self, s: str, p: str) -> bool:

        m, n = len(s), len(p)

        dp = [[False] * (n + 1) for _ in range(m + 1)]

        dp[0][0] = True

        for j in range(2, n + 1, 2):

            dp[0][j] = dp[0][j - 2] and p[j-1] == '*'

        for i in range(1, m+1):

            for j in range(1, n+1):

                dp[i][j] = dp[i][j-2] or dp[i-1][j] and (s[i-1] == p[j-2] or p[j-2] == '.')\

                           if p[j-1] == '*' else \

                           dp[i-1][j-1] and (s[i-1] == p[j-1] or p[j-1] == '.')

        return dp[-1][-1]

Level11. 不同路径
解题思路：
  由于在一个格子中只能向右或者向下走，那么（1）在i， j 都大于0的情况下（考虑中间不在边缘的格子）， 每个格子只能由其上和左边的格子走到，因此每个格子的路径数可由这两个格子的路径和组成，如右图（[坏笑]），
（2）边缘的格子只有一种路径，一直向右或者一直向下。
状态定义： dp[ i ] [ j ] 表示到第 i行 j列共有dp[ i ] [ j ]种路径。
那么转移方程也就有了：i，j不为0时：
dp[i][j] = dp[i-1][j] + dp[i][j-1]
否则为 dp[i][j] = 1

代码实现如下：
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[1] * n for _ in range(m)]
        for i in range(1, m):
            for j in range(1, n):
                if i > 0 and j > 0:
                    dp[i][j] = dp[i-1][j] + dp[i][j-1]
        return dp[-1][-1]

Level. 13 最长递增子序列

* 状态定义：   dp[ i ] 代表以 nums[ i ]为末尾的最长子序列的长度。

* 状态转移方程：

                思路： 因为 dp[ j ] 这一子序列已经是严格递增序列，因此 j 属于 [ 0  ,  i) 范围内时，

 (1)只要满足dp[ i ] > dp[ j ] 就可以将dp[ i ] 插入 dp[ j ]序列的末尾, 再使长度+1，dp[ i ] = max( dp[ i ] , dp[ j ] + 1 )

(2)  若 dp[ i ] <= dp[ j ] 就跳过不做处理

* 方程： `dp[i] = max(dp[i], dp[j] + 1) for j in [0, i)`。

* 初始状态 : dp中每个元素都算是一个递增序列， 所以初值均为1

* 返回值： 返回dp数组的最大值，即得到全局最长递增子序列。

* 复杂度分析：
  时间复杂度 O(N2 ) ： 遍历计算 dp 列表需 O(N)，计算每个 dp[i] 需 O(N)  ( max 函数执行复杂度）。
  空间复杂度 O(N) ： dp 列表占用线性大小额外空间。

代码实现：

class Solution:

    def lengthOfLIS(self, nums: List[int]) -> int:

        dp = [1] * len(nums)

        for i in range(len(nums)):

            for j in range(i):

                if nums[j] < nums[i]:

                    dp[i] = max(dp[i], dp[j] + 1)

        return max(dp)

* 降低时间复杂度： 遍历计算dp列表需要的时间复杂度O( N ) 不可避免， 但计算每个dp[ i ]  也需要O( N ) 可以改善。
  因此我们（K神）考虑：是否可以通过重新设计状态定义，使整个 dp 为一个排序列表；这样在计算每个 dp[k] 时，就可以通过二分法遍历 [0,k) 区间元素，将此部分复杂度由 O(N) 降至 O(logN)。
  
  * 状态转移设计：
  
  * 设常量数字 N，和随机数字 x，我们可以容易推出：当 N 越小时，N<x 的几率越大。例如： N=0 肯定比 N=1000 更可能满足 N<x。
  
  * 在遍历计算每个 tails[k]，不断更新长度为 [1,k] 的子序列尾部元素值，始终保持每个尾部元素值最小 （例如 [1,5,3]]， 遍历到元素 5 时，长度为 2 的子序列尾部元素值为 5；当遍历到元素 3 时，尾部元素值应更新至 3，因为 3 遇到比它大的数字的几率更大）。
  
  * **tails 列表一定是严格递增的：** 即当尽可能使每个子序列尾部元素值最小的前提下，子序列越长，其序列尾部元素值一定更大。
    
    * 状态定义： tailes[ k ] 的值代表长度为 K + 1子序列的尾部元素值
    
    * 转移方程：设 res 为 tails 当前长度 ， 通过二分法遍历[0, res)列表区间， 找出nums[k] 的大小分界点，会出现两种情况：
    
    * （1）区间中存在 tails[i]>nums[k] ： 将第一个（即tails数组最后一个，同时也是tails数组的最大值） 满足 tails[i]>nums[k] 执行 tails[i]=nums[k] ；因为更小的 nums[k] 后更可能接一个比它大的数字（前面分析过）。
      （2）区间中不存在 tails[i]>nums[k] ： 意味着 nums[k] 可以接在前面所有长度的子序列之后，因此肯定是接到最长的后面（长度为 res ），新子序列长度为 res+1。
      
      * 初始状态：
        令 tails 列表所有值 =0。
    
    * **返回值：**
      
      * 返回 res ，即最长上升子子序列长度。
  
  class Solution:
      def lengthOfLIS(self, nums: List[int]) -> int:
          tails, res = [0]  * len (nums) , 0
          for num in nums :
              i, j = 0, res
              while i < j :
                  m = (i + j) // 2
                  if tails[m] < num : i = m + 1
                  else : j = m
              tails[i] = num
              if j == res : res += 1
          return res
  复杂度分析：
  时间复杂度 O(NlogN) ： 遍历 nums 列表需 O(N)，在每个 nums[i] 二分法需 O(logN)。
  空间复杂度 O(N) ： tails 列表占用线性大小额外空间。

装满石头的背包的最大数量

capacity = [2,3,4,5], rocks = [1,2,4,4],

共有多余石头 additionalRocks 个

贪心思想： 每次先装满，需要数量最少的石头才能装满的背包，

首先将每个已装石头的数目和容量差值，插入一个数组，并排序升序排（这样每次遇到未满的背包都是需要石头数量最少的背包，从而使满背包的数量最大化）。

代码实现：

class Solution:

    def maximumBags(self, capacity: List[int], rocks: List[int], additionalRocks: int) -> int:

        cnt = 0

        temp = [0] * len(capacity)

        for i in range(len(capacity)):

            temp[i] = capacity[i] - rocks[i]

        temp.sort()



        for t in temp:

            if not t or additionalRocks >= t:    // not t 代表 not 0 即已经装满的背包，数量+1

                additionalRocks -= t

                cnt+=1

        return cnt

解题思路：

根据题意，五个朝代连续的充分条件是：

（1）每个朝代不能重复（重复必不连续）， 可包含多个0

（2）设五个朝代中最大朝代为ma， 最小为mi， 则有 ma - mi  < 5

方法一： 辅助哈希表

（1）遍历朝代，遇到0 就跳过

（2）判断重复，利用Set函数实现遍历判重， Set的查找方法时间复杂度为O( 1 )， 若有重复提前返回False

（3）获取最大/ 最小 的朝代： 借助辅助变量ma mi, 遍历统计

复杂度分析：

（1）时间复杂度O ( 1 )： O( N ) = O( 5 ) = O ( 1 )

（2）空间复杂度O ( 1 )： 用于判重的辅助 Set 使用 O( N ) = O( 1 ) 额外空间。

补充知识：**set()** 函数创建一个无序不重复元素集，可进行关系测试，删除重复数据，还可以计算交集、差集、并集等。



代码实现如下：

class Solution:
    def checkDynasty(self, places: List[int]) -> bool:
        repeat = set()
        ma, mi = 0, 14
        for place in places:
            if place == 0: continue # 跳过未知朝代
            ma = max(ma, place) # 最大编号朝代
            mi = min(mi, place) # 最小编号朝代
            if place in repeat: return False # 若有重复，提前返回 false
            repeat.add(place) # 添加朝代至 Set
        return ma - mi < 5 # 最大编号朝代 - 最小编号朝代 < 5 则连续 



方法二：排序 + 遍历

解题思路：

（1）先对数组排序，方便对重复数字做处理，即排序后遍历数组，判断  places[i] = places[i+1]    是否成立来判重

（2）获取最大 / 最小的朝代： 排序后，数组末位元素 places[4] 为最大编号朝代；元素 places[unknown] 为最小编号朝代，其中 unknown 为未知朝代的数量。

class Solution:

    def checkDynasty(self, places: List[int]) -> bool:

        places.sort()

                return False 

        return places[4] - places[unknown] < 5

0xffffffff  0x代表16进制，每个f 十进制为 15 代表 二进制 1111

所以0xffffffff表示 1111 1111 1111 1111 1111 1111 1111 1111  

* 十进制表示： 无符号整数 (unsigned int)：0xffffffff 表示 4294967295。 有符号整数 (signed int)：0xffffffff 表示 -1，因为最高位（符号位）为 1，表示负数。
* 补码规则： 在计算机中，负数以 补码 形式存储。 对于 0xffffffff： 它是 -1 的补码。 计算原码：符号位保持不变，其余位取反加 1，结果为 -1。

0x7fffffff 0x代表16进制，每个f 十进制为 15 代表 二进制 1111，7代表 0111

所以0x7fffffff表示0111 1111 1111 1111 1111 1111 1111 1111  共32位（bit）== 8 B

表示有符号数的最大值，2^31 - 1    第一位符号位为0代表正数

使用场景

* 0x7fffffff 常用于算法中表示无穷大，尤其是在图论中计算最短路径时。

* 它也可以用 INT_MAX 常量来替代。

* 在某些情况下，可能需要一个比 0x7fffffff 小的数来避免整数溢出，例如 0x3fffffff 或 0x3f3f3f3f。

Python，Java, C++ 等语言中的数字都是以 补码 形式存储的。但 Python 没有 int , long 等不同长度变量，即在编程时无变量位数的概念。

获取负数的补码： 需要将数字与十六进制数 0xffffffff 相与。可理解为舍去此数字 32 位以上的数字（将 32 位以上都变为 0 ），从无限长度变为一个 32 位整数。

正数的补码还是其本身。

解题思路：

观察图中所示，发现，无进位和与异或算法规律相同，进位和与算法规律相同（再左移一位）

res = dataA+dataB ⇒ res=n+c

循环求 n 和 c ，直至进位 c=0 ；此时 s=n ，返回 n 即可

返回前数字还原： 若补码 dataA 为负数（ 0x7fffffff 是最大的正数的补码 ），需执行 ~(dataA ^ x) 操作，将补码还原至 Python 的存储格式。dataA ^ x 运算将 1 至 32 位按位取反；~ 运算是将整个数字取反；因此，~(dataA ^ x) 是将 32 位以上的位取反，1 至 32 位不变。

代码实现如下：

class Solution:

    def encryptionCalculate(self, dataA: int, dataB: int) -> int:

        standard = 0xffffffff

        dataA, dataB = dataA & standard, dataB & standard

        while dataB != 0 :

            dataA, dataB = (dataA ^ dataB), (dataA & dataB) << 1 & standard

        return dataA if dataA <= 0x7fffffff else ~(dataA ^ standard)
