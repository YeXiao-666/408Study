匈牙利算法-指派问题
输入：n×n成本矩阵C
输出：最小成本分配方案及总成本

1. 行归约：
   for i in C :
      min_row = min(C[i][0], C[i][1], ..., C[i][n-1])
       for j in 行i:
           C[i][j] = C[i][j] - min_row

2. 列归约：
   for j in C:
       min_col = min(C[0][j], C[1][j], ..., C[n-1][j])
       for i in j:
           C[i][j] = C[i][j] - min_col

3. 查找完美匹配（每个人对应自己的工作，即0不同列不同行）
：
   （1）构造辅助图：边(i,j)存在当且仅当C[i][j] == 0
  （2） 寻找最大匹配：
      使用DFS或BFS在辅助图中找最大匹配，记录匹配结果match[]
   （3） 若匹配数等于n（n个0不同列不同行）停止搜索，return 分配结果
  （4） 否则，剩余没有划分的行列，取行（列）最小元素
（5） 找到未被覆盖的最小元素d：
         d = min{C[i][j]}
   （6）调整矩阵：
         划分线交点的元素  += d;
          剩余没有划分的行列 -= d;

4. 提取分配方案：
   for i in match[]:
       分配第i个人到第match[i]个工作

返回分配方案
