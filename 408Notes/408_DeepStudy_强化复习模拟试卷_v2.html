1.数据结构
设一个带头结点的单链表 $L$ 的头指针为 $head$，结点结构为 $\{data, next\}$。以下算法的功能是：
void Algorithm(Node* head){
    Node *p = head->next, *q;
    head->next = NULL;
    while (p != NULL){ q=p->next; p->next=head->next; head->next=p; p=q; }
}
A删除链表中所有重复元素
B将链表原地逆置（头插法重建）
C将链表按值升序排列
D将链表中奇数位元素移到偶数位之前
✅ 正确答案：B
核心分析：该算法采用"头插法"逐个摘下原链表结点并插入到新链表的头部，最终效果是将原链表原地逆置。时间复杂度 $O(n)$，空间复杂度 $O(1)$。这是链表逆置的经典写法，与2013年408真题第41题考查方式一致——要求考生理解指针操作的语义而非死记硬背代码。

A顺序表；单链表
B静态链表；双链表
C顺序表；双链表

4.数据结构

6.数据结构
具有$n$个结点的满二叉树（Full Binary Tree），叶结点数为______，度为$2$的结点数为______。
A$\frac{n+1}{2}$；$\frac{n-1}{2}$
B$\frac{n}{2}+1$；$\frac{n}{2}-1$
C$\frac{n}{2}$；$\frac{n}{2}-1$
D$n-1$；$1$
✅ 正确答案：A
对任意非空二叉树恒有 $n_0 = n_2 + 1$（重要性质！）。满二叉树所有分支结点度均为$2$，故 $n= n_0+n_2 = 2n_0-1$ → $n_0=\frac{n+1}{2}$，$n_2=\frac{n-1}{2}$。
🔗 此性质在哈夫曼树构建中用于验证编码总长度最优性，同时与操作系统进程调度中的多叉树结构有内在联系。

B$O(n\log n)$；$O(\log n)$；$O(n\log n)$

    Node* pre = L;
    Node* p = L->next;
    while (p != NULL) {
        if (p->data == x) {
            Node* q = p; p = p->next;
            pre->next = p; free(q);
        } else { pre = p; p = p->next; }
    }
}

二叉链表存储的二叉树，设计算法：

📝 参考答案要点：

(1) 非递归中序遍历（5分）：沿左分支入栈保存路径→栈顶弹出并访问→转向右子树。栈的作用是记录回溯路径。

void InOrder(BiTree T){
    InitStack(S); BiTNode* p=T;
    while(p||!IsEmpty(S)){
        if(p){Push(S,p);p=p->lchild;}
        else{Pop(S,p);visit(p->data);p=p->rchild;}
    }
}

(2) 求宽度（8分）：利用层序遍历（BFS），每轮处理一层。关键：用$levelSize=QueueLength(Q)$记录当前层数量，恰好弹出这么多结点。时间$O(n)$，空间$O(w)$。

int GetWidth(BiTree T){
    if(!T) return 0; LinkQueue Q; InitQueue(Q);
    EnQueue(Q,T); int maxW=0;
    while(!isEmpty(Q)){
        int ls=QueueLength(Q);
        maxW=max(maxW,ls);
        for(int i=0;i<ls;i++){
            BiTNode* node; DeQueue(Q,node);
            if(node->lchild) EnQueue(Q,node->lchild);
            if(node->rchild) EnQueue(Q,node->rchild);
        }
    } return maxW;
}

void Worker(){
    while(true){
        生产产品item;
        P(empty);      // 申请空位
        P(mutex);      // 进入临界区
        放入item; in=(in+1)%N;

    while(true){

        V(mutex);      // 退出临界区
