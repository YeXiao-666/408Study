1.当采用顺序存储结构存储一个长度为 n 的线性表时，在保持表中元素相对顺序不变的前提下，下列操作中必然导致元素移动的是（）
Ⅰ. 在表头位置插入一个新元素    Ⅱ. 删除表头位置的元素
Ⅲ. 在表尾位置插入一个新元素    Ⅳ. 删除表尾位置的元素
【考点：顺序表的插入与删除操作 — 元素移动分析】
A.仅Ⅰ、Ⅱ
B.仅Ⅰ、Ⅲ
C.仅Ⅱ、Ⅳ
D.仅Ⅲ、Ⅳ
✅ 正确答案：A
📖 解析：在顺序表（数组）中：
• 表头插入：需要将全部 n 个元素后移一位 → 移动 n 次 ✓
• 表头删除：需要将后面 n−1 个元素前移一位 → 移动 n−1 次 ✓
• 表尾插入：直接在末尾追加，无需移动任何元素 ✗
• 表尾删除：直接减少表长，无需移动任何元素 ✗
因此必然导致元素移动的是Ⅰ和Ⅱ。选A。
💡 命题关联：2026真题第1题考查同一知识点（数组内存复制/元素移动），本题为同考点变式训练。
2.设有一个双向链表 L，每个结点的结构为 [prior, data, next]，其中 prior 指向前驱，next 指向后继。若要将链表中每个结点的 prior 指针改为指向该结点的后继的后继（即 prior = next->next），则下列代码段正确的是（）
【考点：双向链表指针操作 — 边界条件处理】
A.while(p!=NULL){p->prior=p->next->next;p=p->next;}
B.while(p!=NULL&&p->next!=NULL){p->prior=p->next->next;p=p->next;}
C.while(p!=NULL){if(p->next!=NULL){p->prior=p->next->next;p=p->next;}}
D.while(p!=NULL){if(p->next!=NULL)p->prior=p->next->next;p=p->next;}
✅ 正确答案：D
📖 解析：关键在于边界条件的正确处理：
• 当 p->next 为 NULL 时，访问 p->next->next 会产生空指针异常，因此必须先判断 p->next != NULL
• 无论 next 是否为 NULL，都需要执行 p = p->next 使指针前进到下一个结点
• 选项 C 中若 next 为 NULL 则不执行 p=p->next，导致死循环 ✗
• 选项 D 正确：先检查 next 是否非空再修改 prior，然后无条件推进 p ✓
💡 命题关联：对应2026真题第2题（双向链表指针操作），本题增加了对循环终止条件和空指针处理的深度考查。
3.已知二叉树 T 的中序遍历序列为 $\{b,d,a,g,c,e,f\}$，层次遍历序列为 $\{a,b,c,d,e,f,g\}$，则该二叉树的后序遍历序列为（）
【考点：二叉树遍历序列还原 — 中序+层次→后序】
A.$\{d,g,b,e,f,c,a\}$
B.$\{d,g,b,e,f,c,a\}$ 变式
C.$\{g,d,b,f,e,c,a\}$
D.$\{d,b,g,f,e,c,a\}$
✅ 正确答案：B
📖 解析：
步骤一：由层次遍历知根结点为 $a$
步骤二：在中序序列 $\{b,d,\mathbf{a},g,c,e,f\}$ 中，$a$ 左侧 $\{b,d\}$ 为左子树，右侧 $\{g,c,e,f\}$ 为右子树
步骤三：层次遍历第二层为 $\{b,c\}$ → 左子树根为 $b$，右子树根为 $c$
步骤四：递归构建左子树：中序 $\{b,d\}$ 层次含 $b,d$ → $b$ 的右孩子为 $d$
步骤五：递归构建右子树：中序 $\{g,c,e,f\}$ 层次含 $c,e,f,g$ → $c$ 的左子树含 $g$，右子树含 $e,f$
最终树结构：a 为根；a 左孩子 b，b 无左孩子、右孩子 d；a 右孩子 c，c 左孩子 g，右孩子 e，e 右孩子 f
后序遍历：左→右→根 → $\{d, g, b, f, e, c, a\}$

6.采用邻接表存储有向图 G，若要求计算图中某个顶点 v 的入度，则时间复杂度为（）
【考点：图的存储结构 — 邻接表入度计算复杂度】
A.$O(|V|)$
B.$O(\min(|V|,|E|))$
C.$O(|E|)$
D.$O(\max(|V|,|E|))$
✅ 正确答案：C
📖 解析：在邻接表中，每个顶点维护一个出边链表。要计算顶点 v 的入度，需要遍历所有顶点的出边链表，统计指向 v 的边数。因此需要扫描所有边，时间复杂度为 $O(|E|)$。
若使用邻接矩阵存储，入度可直接通过扫描 v 对应的一列得到，复杂度同样为 $O(|V|)$。
若要频繁查询入度，可维护一个入度数组，在建图时同步更新。
💡 命题关联：直接对应2026真题第6题。

25.两个进程 P 和 Q 并发执行，它们的读集合和写集合分别为 R(P)、W(P)、R(Q)、W(Q)。P 和 Q 并发执行不会出现数据竞争（并发错误）的充要条件是（）
【考点：Bernstein条件 — 并发正确性判定】
A.R(P)∩W(P)=∅ 且 W(P)∩W(Q)=∅
B.R(P)∩W(Q)=∅ 且 R(Q)∩W(P)=∅ 且 W(P)∩W(Q)=∅
C.R(P)∩R(Q)=∅ 且 R(P)∩W(Q)=∅
D.R(P)∩W(P)=∅ 且 R(Q)∩W(Q)=∅ 且 W(P)∩W(Q)=∅
✅ 正确答案：B
📖 解析：Bernstein 条件（1976）：
两个进程并发执行结果等价于某种串行执行的充要条件：
$$R(P) \cap W(Q) = \emptyset \quad \text{且} \quad R(Q) \cap W(P) = \emptyset \quad \text{且} \quad W(P) \cap W(Q) = \emptyset$$
含义：
① P 读的数据不被 Q 写（P 不会读到 Q 的半成品）
② Q 读的数据不被 P 写（同理）
③ P 和 Q 不写同一数据（不会有写-写冲突）
注意：R(P)∩W(P)=∅ 不是必要条件（同一进程内读写自身数据是正常的）。

41.（12分）已知二叉搜索树（BST）采用二叉链表存储，类型定义如下：
typedef struct BSTNode {
    int data;                // 关键字值
    struct BSTNode *left;   // 左孩子指针
    struct BSTNode *right;  // 右孩子指针
} BSTNode, *BSTree;

要求：

（1）给出算法的基本设计思想。（4分）
（2）根据设计思想，采用 C/C++ 语言描述算法，关键之处给出注释。（8分）

📝 参考答案：

（1）算法基本设计思想：

利用二叉搜索树的有序性（中序遍历为递增序列），从根结点出发进行搜索：

  • 维护全局变量 minDiff（当前最小差值，初始为 ∞）和结果列表
  • 对 BST 进行中序遍历，在遍历过程中计算每个结点值与 k 的差的绝对值
  • 若当前差值 < minDiff，更新 minDiff 并清空结果列表，加入当前结点
  • 若当前差值 == minDiff，将当前结点追加到结果列表
  • 剪枝优化：若当前结点值 > k 且 (当前值 - k) ≥ minDiff，则无需遍历右子树（因为右子树值更大，差值只会更大）

时间复杂度 O(n)，最坏情况下需访问所有结点；平均情况下可提前终止。空间复杂度 O(h)，h 为树高。

（2）算法实现（C语言）：

int minDiff = INT_MAX;   // 全局最小差值
int results[100];        // 结果数组
int count = 0;           // 结果个数

// 中序遍历查找最接近 k 的结点
void inorderSearch(BSTNode *node, int k) {
    if (node == NULL) return;
    
    // 剪枝：若当前值已超过 k + minDiff，右子树无需遍历
    if (node->data > k && (node->data - k) >= minDiff) {
        inorderSearch(node->left, k);  // 只需遍历左子树
        return;
    }
    
    // 先遍历左子树（值较小的部分）
    inorderSearch(node->left, k);
    
    // 处理当前结点
    int diff = abs(node->data - k);
    if (diff < minDiff) {
        minDiff = diff;
        results[0] = node->data;
        count = 1;
    } else if (diff == minDiff) {
        results[count++] = node->data;
    }
    
    // 再遍历右子树（值较大的部分）
    // 剪枝：若当前值小于 k 且 (k - 当前值) >= minDiff，左子树已在上面的递归中处理
    inorderSearch(node->right, k);
}

void findClosest(BSTree root, int k) {
    minDiff = INT_MAX;
    count = 0;
    inorderSearch(root, k);
    
    printf("最小差值: %d\n", minDiff);
    printf("符合条件的结点值:");
    for (int i = 0; i < count; i++)
        printf(" %d", results[i]);
    printf("\n");
}

（2）EXTOP 至少需要 16 位输出。原因：M 型指令的 offset 需要与 16 位基址寄存器相加生成 16 位地址，8 位有符号数经符号扩展后需变成 16 位才能参与运算。I 型的 imm8 同理需扩展到 16 位。

（3）取指周期的控制信号：

  • MARSrc = 00（PC 值送 MAR）
  • ALUASrc = 0（PC 送 ALU 的 A 端口）
  • ALUBSrc = 01（常数 4 送 ALU 的 B 端口，PC+4）
  • RegWr = 1（写回 PC 值）

（4）SHL 指令执行周期：

  • ALUBSrc：选择移位量（来自指令的功能字段或立即数）
  • RegWSrc = 01（ALU 结果写回寄存器）
  • RegDst = Rd（目标寄存器号来自指令的 Rd 字段）
  • RegWr = 1（允许写回）

EXtop 可以与 M 型指令共用：SHL 指令不需要符号扩展（移位量为无符号数），但在数据通路中 EXtop 的输出只在特定指令类型中被选中，不会产生冲突。

📗 计算机网络综合题（第47题，共9分）
47.（9分）假设主机 C 与服务器 Si 之间建立一条 TCP 连接，C 向 Si 上传一个总长度为 3000B 的文件。已知：
  • C 的拥塞窗口初始阈值 ssthresh = 16MSS（最大报文段长度 MSS = 500B）
  • Si 对收到的每个报文段进行确认（累积确认），确认报文不封装数据
  • 接收窗口 rwnd 始终为 2000B
  • RTT（往返时间）= 20ms
  • C 选择的初始序号 seq = 1000，Si 的初始序号 = 5000
  • 整个传输过程中未出现任何重传或报文丢失
请回答：
（1）C 与 Si 建立 TCP 连接需要几次握手？C 收到的第二个报文段（SYN+ACK）的 seq 和 ack 各是多少？（2分）
（2）当 C 收到 Si 发送的确认报文段 ack=2501, rwnd=2000 后，C 的拥塞窗口 cwnd 增大到多少？发送窗口是多少？（2分）
（3）C 与 Si 释放 TCP 连接需要几次挥手？C 收到的最后一个 FIN 报文段的 seq、ack 和 FIN 标志值？（3分）
（4）忽略报文传输时延，从 C 请求建立连接起到确定 Si 成功接收到整个文件为止，经过了多少时间？（2分）

📝 参考答案：

（1）TCP 建立连接需要 3 次握手：
• 第 1 次：C → Si，SYN=1, seq=1000
• 第 2 次：Si → C，SYN=1, ACK=1, seq=5000, ack=1001（确认 C 的序号 1000，期望下一个字节为 1001）
• 第 3 次：C → Si，ACK=1, seq=1001, ack=5001

（2）文件 3000B，MSS=500B → 需要发送 6 个报文段。
慢开始阶段：cwnd 从 1MSS 开始指数增长（每收到一个 ACK 加 1MSS）：
• 第 1 个 ACK 后：cwnd = 2MSS = 1000B
• 第 2 个 ACK 后：cwnd = 4MSS = 2000B
• ...
收到 ack=2501（表示已确认到字节 2501，即 1501B 数据被确认，对应第 4 个报文段发送完毕后的确认）：
此时 cwnd 取决于慢开始的进展...
发送窗口 = min(cwnd, rwnd) = min(cwnd, 2000)

（3）TCP 释放连接需要 4 次挥手：
• C 发送 FIN（主动关闭）
• Si 回复 ACK
• Si 发送 FIN（数据发送完毕）
• C 回复 ACK
最后一个 FIN 报文段由 Si 发送，seq = 5000 + Si 发送的数据字节数（若 Si 只发了确认段未发数据，则 seq = 5000 或 5001），ack = C 的下一个期望序号，FIN = 1。

（4）总时间估算：
• 3 次握手：1 RTT = 20ms
• 数据传输：6 个报文段，无流水线限制（cwnd 很快增长）→ 约 1-2 RTT
• 4 次挥手：2 RTT（Si 的 FIN 可能延迟发送）
• 总计约 60~80ms（粗略估计，精确值需按 cwnd 增长逐步计算）
