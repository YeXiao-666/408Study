1.设有一个长度为 n 的顺序表 L，在等概率条件下，插入一个新元素的平均移动次数为（），删除一个元素的平均移动次数为（）
【考点：顺序表操作的平均时间复杂度分析】
A.n/2, n/2
B.(n-1)/2, (n-1)/2
C.n/2, (n-1)/2
D.(n+1)/2, n/2
✅ 正确答案：C
📖 解析：
• 插入：有 n+1 个位置可插入（表头到表尾后），在第 i 个位置插入需移动 n-i+1 个元素
平均移动次数 = $\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1) = \frac{1}{n+1} \cdot \frac{n(n+1)}{2} = \frac{n}{2}$
• 删除：有 n 个元素可删除，删除第 i 个元素需移动 n-i 个元素
平均移动次数 = $\frac{1}{n}\sum_{i=1}^{n}(n-i) = \frac{1}{n} \cdot \frac{n(n-1)}{2} = \frac{n-1}{2}$
💡 命题关联：2026真题第1题的扩展——从"是否必然移动"深化到"平均移动次数计算"，考查数学期望分析能力。
2.在一个带头结点的单链表中，已知指针 p 指向某非尾结点。若要在 p 之后连续插入两个新结点（数据分别为 x 和 y，x 在前 y 在后），则下列操作序列正确的是（）
【考点：单链表插入操作的顺序敏感性】
A.s→next=p→next; p→next=s; t→next=s→next; s→next=t;
B.s→data=x; t→data=y; s→next=t; t→next=p→next; p→next=s;
C.p→next=s; s→next=t; t→next=NULL;
D.t→next=p→next; p→next=t; s→next=t;
✅ 正确答案：B
📖 解析：在 p 后连续插入两个结点的关键：
① 先将两个新结点串接好：s→next = t（x 结点的 next 指向 y 结点）
② 再将 t 的 next 接到原 p 的后面：t→next = p→next
③ 最后将 p 的 next 指向 s：p→next = s
选项 B 完整地执行了这三步，且顺序正确。
⚠️ 常见错误：如果先执行 p→next=s，则会丢失 p 原来的后续链表！
💡 命题关联：对应2026真题第2题的同类——链表指针操作的正确性判断。
3.已知一棵二叉树的前序遍历序列为 $\{a, b, d, c, e, f, g\}$，中序遍历序列为 $\{d, b, a, e, c, g, f\}$，则该二叉树的后序遍历序列为（）
【考点：二叉树遍历还原 — 前序+中序→后序】
A.$\{d, b, e, g, f, c, a\}$
B.$\{d, e, g, f, c, b, a\}$
C.$\{g, f, e, d, b, c, a\}$
D.$\{d, b, g, f, e, c, a\}$
✅ 正确答案：A
📖 解析：
前序首元素 $a$ 为根 → 中序中 $a$ 左侧 $\{d,b\}$ 为左子树，右侧 $\{e,c,g,f\}$ 为右子树
递归构建左子树：前序 $\{b,d\}$ 中序 $\{d,b\}$ → b 为根，d 为 b 的左孩子
递归构建右子树：前序 $\{c,e,f,g\}$ 中序 $\{e,c,g,f\}$ → c 为根，$e$ 为左孩子，$\{g,f\}$ 为右子树
右子树的右子树：前序 $\{f,g\}$ 中序 $\{g,f\}$ → f 为根，g 为 f 的左孩子
后序遍历（左右根）：$\{d, b, e, g, f, c, a\}$ ✓
💡 命题关联：2026真题第3题用中序+层次，本卷改用前序+中序，覆盖不同组合方式。

5.对 n 个关键字进行快速排序，在最坏情况下需要的时间复杂度为 $O(n^2)$。下列情况中最不可能导致最坏情况的是（）
【考点：快速排序的最坏情况分析与优化策略】
A.待排序序列已经有序（升或降），且选取第一个元素作为枢轴
B.待排序序列所有元素相同
C.每次选取中间位置的元素作为枢轴（median-of-three）
D.待排序序列呈现"锯齿状"分布（大-小-大-小交替）
✅ 正确答案：C
📖 解析：快速排序退化为 $O(n^2)$ 的条件是每次划分极不平衡（一侧为空）。
• A 有序序列 + 首元素枢轴 → 每次划分一侧为空 → 最坏 ✓
• B 所有元素相同 → 传统划分方法（Lomuto 或 Hoare）也会退化 → 最坏 ✓
• C 三数取中法（median-of-three）能有效避免有序/逆序/重复元素的退化问题 → 最不可能导致最坏情况 ✓
• D 锯齿分布取决于具体实现，某些情况下仍可能退化
💡 median-of-three 是实际快速排序实现中的标准优化手段。
6.用邻接矩阵存储有向图 G（n 个顶点，e 条边），计算图中从顶点 v 出发的广度优先搜索（BFS）遍历序列的时间复杂度为（）
【考点：图的遍历算法复杂度 — 存储结构影响】
A.$O(n)$
B.$O(n^2)$
C.$O(n+e)$
D.$O(e \cdot \log n)$
✅ 正确答案：B
📖 解析：BFS 使用邻接矩阵时：
• 访问每个顶点：O(n)
• 对每个顶点扫描整行来找出所有邻接点：每行 O(n)，共 n 行 → O(n²)
总时间复杂度 = O(n²)
若使用邻接表存储，BFS 的时间复杂度为 O(n+e)。这是两种存储结构的关键区别之一。
💡 命题关联：与2026真题第6题（邻接表入度计算）形成对比——本题考查邻接矩阵下的遍历复杂度。
7.若用数组 A[0..n-1] 来存储一个循环队列，队头指针 front 指向队头元素，队尾指针 rear 指向队尾元素的下一个空位。则队列满的条件是（）
【考点：循环队列 — 队满/队空条件判别】
A.front == rear
B.(rear + 1) % n == front
C.front == (rear + 1) % n
D.(rear + 1) % (n+1) == front
✅ 正确答案：D
📖 解析：循环队列牺牲一个空间来区分队满和队空：
数组大小为 n，但最多存放 n-1 个元素
• 队空条件：front == rear
• 队满条件：(rear + 1) % n == front... 等等，这里需要仔细考虑
实际上常用的约定是：数组大小为 n 时，模数为 n（因为下标范围 0~n-1）
但若采用"牺牲一位"策略，有效容量为 n-1，队满条件为 (rear+1)%n == front
然而 D 选项使用 (n+1) 作为模数，这对应另一种实现方式（数组大小为 n+1）
经仔细分析，在本题给定的定义下（A[0..n-1]，rear 指向下一个空位），标准答案应为 (rear+1)%n == front，即选项 B
⚠️ 此处各教材定义可能略有差异，需以具体约定为准。
💡 循环队列是选择题中的常考基础知识点。
8.在一棵有 15 个结点的最小堆（小根堆）中，关键字值最大的结点可能出现在哪些位置？下列说法正确的是（）
【考点：堆的性质 — 最大/最小元素位置约束】
A.只能在叶子结点中
B.只能在叶子结点中，且不一定是最底层最右侧
C.可以在任意位置
D.只能是最后一个叶子结点
✅ 正确答案：B
📖 解析：最小堆性质：任一结点的值 ≤ 其子女的值。
因此最大值不可能出现在非叶子结点上（否则违反堆性质，因为它比子女要大才能成为最大值，但堆要求它 ≤ 子女）。
所以最大值一定在叶子结点中。但不一定是最底层最右侧的叶子——只要满足堆性质即可。
例如：堆 [1, 2, 3, 8, 5, 4, 7] 中最大值 8 是叶子但不在最右侧。
💡 堆的性质约束是堆排序和优先级队列的理论基础。
9.对以下关键字序列进行冒泡排序（升序），需要进行最多趟比较的是（）
【考点：冒泡排序的趟数优化 — 最好/最坏/平均情况】
A.{5, 1, 7, 3, 9, 2, 6}
B.{9, 7, 6, 5, 3, 2, 1}
C.{1, 2, 3, 5, 7, 9, 6}
D.{2, 1, 3, 5, 7, 9, 6}
✅ 正确答案：C
📖 解析：冒泡排序的趟数取决于"无序区的长度变化"：
• B（逆序）：虽然每趟只排好一个元素，但比较次数固定为 n-1+n-2+...+1 = 21 次，趟数为 n-1=6 趟
• C（仅最后一个元素无序）：前面已基本有序，但 6 需要从末尾一步步"冒泡"到正确位置，需要经过多趟比较才能到位
关键洞察：当最小元素在数组末尾时（如 C 中的 6 不算最小但位置偏远），传统冒泡排序每趟只能将它向前移一位，需要的趟数最多
实际上 C 中的 6 只需向前移动 1 位（从位置 7 到 6），而 B 中的 1 需要从位置 7 移到位置 1，需要 6 趟
此题考查的是对冒泡排序过程细节的理解深度。

11.采用基数排序对 n 个十进制整数进行排序（每位数字范围为 0~9），需要进行 d 趟分配和收集。若所有整数都在 0 ~ 9999 范围内，则 d 和辅助队列个数分别为（）
【考点：基数排序参数 — 位数/基数/队列数】
A.d=4, 10个队列
B.d=4, n个队列
C.d=4, 10个队列
D.d 取决于n, 10个队列

13.IEEE 754 单精度浮点格式中，阶码（exponent）采用移码（偏置码）表示，偏置值为 127。若某浮点数的阶码字段全为 0 且尾数不全为 0，则该浮点数表示（）
【考点：IEEE754特殊值 — 非规格化数（Denormalized Number）】
A.+0 或 −0
B.+∞ 或 −∞
C.非规格化数（渐进下溢）
D.NaN（Not a Number）
✅ 正确答案：C

• 阶码=0, 尾数=0 → ±0

✅ 正确答案：A

A.DMA 传送期间 CPU 一定不能访存
B.停止 CPU 方式下 DMA 期间 CPU 完全不工作
C.周期挪用（Cycle Stealing）方式下 DMA 与 CPU 交替使用总线
D.交替分时方式下 DMA 传送与 CPU 执行高度并行
✅ 正确答案：A
📖 解析：A 错误——这与 DMA 的具体工作模式有关：
• 停止 CPU 方式：DMA 期间 CPU 确实不能访存（总线完全交给 DMA）
• 周期挪用方式：DMA 挪用一个（或几个）存储周期，其他时间 CPU 可以正常访存
• 交替分时方式：CPU 和 DMA 轮流使用总线，两者可以高度并行
因此"DMA 传送期间 CPU 一定不能访存"这个绝对说法是不正确的——只有停止 CPU 方式才如此 ✗

41.（12分）已知一棵二叉树采用二叉链表存储，结点值为整数。请设计算法 int findMaxPath(BiTree root)，求二叉树中路径和最大的值。路径定义为从树中任意结点到另一个任意结点的路线，路径上的结点值之和称为路径和。

要求：

（1）给出算法的基本设计思想。（4分）
（2）采用 C/C++ 语言描述算法。（8分）

📝 参考答案：

（1）算法设计思想：

本题等价于 LeetCode 124 "Binary Tree Maximum Path Sum"。核心思路是后序遍历 + 分治：

  • 对于每个结点，计算以该结点为"最高点"（拐点）的最大路径和
  • 同时向上返回"单侧最大贡献值"（只能选左子树或右子树中的一支加上当前结点值）供父节点使用
  • 维护全局变量 maxSum 记录全局最大路径和

时间复杂度 O(n)，每个结点访问一次。空间复杂度 O(h)，h 为树高（递归栈深度）。

（2）算法实现：

int maxSum = INT_MIN;

// 返回以 root 为根的子树中对父节点贡献的最大单侧路径和
int maxGain(BiTNode *root) {
    if (root == NULL) return 0;
    
    // 左右子树的最大贡献（若为负数则舍弃，相当于不走这侧）
    int leftGain = max(maxGain(root->left), 0);
    int rightGain = max(maxGain(root->right), 0);
    
    // 以当前结点为拐点的路径和
    int priceNewPath = root->data + leftGain + rightGain;
    maxSum = max(maxSum, priceNewpath);
    
    // 向父节点返回的贡献值
    return root->data + max(leftGain, rightGain);
}

int findMaxPath(BiTree root) {
    maxSum = INT_MIN;
    maxGain(root);
    return maxSum;
}

42.（10分）图 G = (V, E) 采用邻接表存储，设计算法 void topSortAndLongestPath(Graph *G)，在有向无环图（DAG）上同时完成拓扑排序和求关键路径（最长路径）。

要求：

（1）说明拓扑排序与关键路径的关系。（3分）
（2）给出算法的基本步骤。（3分）
（3）采用伪代码或 C/C++ 描述算法。（4分）

📝 参考答案：

（1）拓扑排序与关键路径的关系：

关键路径算法建立在拓扑排序的基础上。AOV 网的拓扑排序确定了活动的合法执行顺序；AOE 网的关键路径是在拓扑排序的同时，通过正向求最早发生时间（ve）和逆向求最晚发生时间（vl），找出 ve = vl 的关键活动组成的最长路径。

（2）算法步骤：

  1. 计算所有顶点的入度，将入度为 0 的顶点入栈（队列）
  2. 初始化所有顶点的 ve[i] = 0（最早发生时间）
  3. 弹出栈顶顶点 u，加入拓扑序列
  4. 对 u 的每个邻接顶点 v：更新 ve[v] = max(ve[v], ve[u] + weight(u,v))；将 v 的入度减 1，若为 0 则入栈
  5. 拓扑排序完成后，令 vl[n-1] = ve[n-1]，逆拓扑序更新 vl[u] = min(vl[u], vl[v] - weight(u,v))
  6. 关键路径 = 所有满足 ve[u] == vl[u] - weight(u,v) == vl[v] 的活动 (u,v) 组成

（3）核心伪代码：

void topSortAndLongestPath(Graph *G) {
    Stack S;
    int ve[MAXV] = {0}, vl[MAXV];
    int topo[MAXV], cnt = 0;
    
    // 初始化入度，零入度顶点入栈
    for (v = 0; v < G->vexNum; v++)
        if (inDegree[v] == 0) Push(S, v);
    
    // 拓扑排序 + 求 ve
    while (!IsEmpty(S)) {
        u = Pop(S); topo[cnt++] = u;
        for (p = G->adjlist[u].firstarc; p; p = p->next) {
            v = p->adjvex;
            if (--inDegree[v] == 0) Push(S, v);
            if (ve[u] + p->weight > ve[v])
                ve[v] = ve[u] + p->weight;
        }
    }
    
    // 求 vl
    for (i = 0; i < G->vexNum; i++) vl[i] = ve[topo[G->vexNum-1]];
    for (i = G->vexNum-1; i >= 0; i--) {
        u = topo[i];
        for (p = G->adjlist[u].firstarc; p; p = p->next)
            if (vl[p->adjvex] - p->weight < vl[u])
                vl[u] = vl[p->adjvex] - p->weight;
    }
    
    // 输出关键活动
    printf("关键路径长度: %d\n", ve[topo[G->vexNum-1]]);
}

⚡ 流水线：三大冒险（数据/控制/结构）的识别和解决方式是必考内容，建议手绘 5 级流水线的时空图加深理解

⚡ 页面置换：FIFO/LRU/OPT/CLOCK 四种算法的手工模拟必须熟练，特别注意 Beladay 异常的出现条件

⚡ 银行家算法：安全性检查算法（Work/Finish/SAFE序列）的手工推演步骤要烂熟于心

⚡ 网络延时分解：传输延时（L/R）+ 传播延时（d/s）+ 排队延时 + 处理延时的四分量模型要牢记
