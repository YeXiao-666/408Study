 
 #极值点与拐点

## （1） 定义法：

极值点：对于fx，存在点x0的某个邻域，该邻域任意一点的函数值均大（小）于等于fx0，则x = x0是极小（大）值点，极值为fx0.

拐点：连续曲线的凹弧与凸弧的分界点。

要求【1】拐点处需连续，【2】判别拐点的凹凸不分前后【3】拐点在曲线上，写为（x0，fx0）的形式。

## （2）必要条件

### 极值点：

**一阶可导点是极值点的必要条件。**

x = x0 为函数fx的极值点的两种情况：【1】fx在x0处一阶导数为0（驻点）（存在必为0）【2】x在x0处一阶导数不存在 如|x|



### 拐点：

**二阶可导点是拐点点的必要条件。**

 （x0，fx0）为函数fx的极值点的两种情况：【1】fx在x0处二阶导数为0（存在必为0）【2】x在x0处二阶导数不存在（且fx在x0处一阶导数可能也不存在） 如x的三分之一次方。

## （3）充分条件

### 极值点：

第一充分条件：

fx在x=x0处连续，且在该点去心邻域内<u>一阶导数</u>存在且该点左右邻域内<u>一阶导数</u>变号，则x=x0是fx的极值点

第二充分条件：

fx在x=x0处二阶可导，且x0处一阶导数为0，二阶导数不为0，则x=x0是fx的极值点。

【1】二阶导fx0 > 0 时， x0 为极小值点

【2】二阶导fx0 < 0 时， x0 为极大值点

第三充分条件：

fx在x=x0处n阶可导，n>=2时，fx0的前n-1阶导数（1，.....， n-1）都为0，n阶导数不为0，且n为<u>**偶数**</u>时

【1】n阶导数  > 0 时， x0 为极小值点

【2】n阶导数 < 0 时， x0 为极大值点



#### 【注】函数n（n>=1） 阶可导，函数必连续



### 拐点

第一充分条件：

fx在x=x0处连续，且在该点去心邻域内<u>二阶导数</u>存在且该点左右邻域内<u>二阶导数</u>变号，则（x0，fx0）是fx的拐点

第二充分条件：

fx在x=x0处三阶可导，且x0处二阶导数为0，三阶导数不为0，则（x0，fx0）是fx的极值点。

【1】二阶导fx0 > 0 时， x0 为极小值点

【2】二阶导fx0 < 0 时， x0 为极大值点

第三充分条件：(无一阶导数为0要求)

fx在x=x0处n阶可导，n>=3时，fx0的前n-1阶导数（2，.....， n-1）都为0，n阶导数不为0，且n为<u>**奇数**</u>时（x0，fx0）是fx的拐点.



## 极值点与拐点的重要结论

【1】曲线的<u>可导点</u>**不可同时**为极值点和拐点，曲线的<u>不可导点</u>**可同时**为极值点和拐点

【2】多项式函数 f（x） = （x - a）^ n  * g（x），g（a）不等于0，则当n为奇数时，点（a， 0）为拐点，n为偶数时，x=x0为极值点

费马定理：
fx在x0处满足（1）可导（2）取极值，则该点一阶导数为0；

罗尔定理：

（1）fx 在闭区间 [ a, b ]上连续

（2）开区间 (a, b) 可导

（3）f（a）= f（b）

则存在 (a, b)内一点 x0,使得 x0处的1阶导数为0;

推广罗尔:

fx在开区间(a, b) 可导, a点右极限函数值等于b点左极限函数值, 则存在 (a, b)内一点 x0,使得 x0处的1阶导数为0;
