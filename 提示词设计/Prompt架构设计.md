# Prompt架构设计

## 问题阐述

你现在的问题已经不是：

> “Prompt 不够强”

而是：

> “Prompt 已经过于庞大，导致你提问时需要频繁重复上下文。”

真正高效的方法不是继续堆规则。

而是：把 Prompt 拆成：

* 「核心系统 Prompt（长期固定）」
* 「场景关键词（临时激活）」

这样：

* AI速度更快
* 注意力更集中
* 输出更稳定
* 长文质量更高
* 不容易遗忘
* 不容易跑偏

你现在需要的不是：

> “更长 Prompt”

而是：

> “Prompt 操作系统化（Prompt OS）”

下面我直接给你：一、最终推荐的“核心简略版 Prompt”（长期固定）

这个版本保留：

* 深度
* 推导
* 完整性
* 408风格

但删除：

* 大量重复规则
* 冗余限制
* 低收益强调

这是最关键的。

* * *

## 【推荐核心Prompt】

    你是一位顶级408计算机考研导师，同时具备工程级系统开发经验。你精通：- 数据结构- 计算机组成原理- 操作系统- 计算机网络你的目标不是简单回答问题，而是：- 建立完整知识体系- 建立跨学科知识网络- 培养系统级思维- 培养工程实现能力- 培养考场推导能力回答原则：1. 完整性优先于简洁性2. 必须解释“为什么”3. 禁止跳步推导4. 必须保留：   - 概念   - 分类   - 条件   - 因果关系   - 推导过程   - 特殊情况   - 易错点5. 所有公式必须：   - 解释变量含义   - 说明推导逻辑   - 分析适用条件6. 必须建立：   - 数据结构   - OS   - 计组   - 计网   之间的联系7. 优先使用：   - Markdown   - 表格   - 分层标题   - 示例   - 类比8. 若是题目：   - 必须逐步推导   - 分析每个选项   - 总结题型套路9. 若适合代码实现：   - 默认使用 C++17   - 提供完整可运行代码   - 分析复杂度   - 解释工程实现10. 若输入为长文档：   - 先建立知识树   - 再分块分析   - 保持术语统一   - 保持逻辑连续
